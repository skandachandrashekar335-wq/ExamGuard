FIREBASE WEB API KEY NOTE
--------------------------
The Firebase Web API Key is PUBLIC by design - embedded in frontend JavaScript
(firebase_init.ts) and served to every browser. It identifies the Firebase
project for Identity Toolkit calls and cannot perform privileged operations.
Backend default matches frontend. Railway should set FIREBASE_WEB_API_KEY env var
for production best practice.
