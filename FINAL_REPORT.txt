AUTH FLOW (CODE VERIFIED, MANUAL USER TEST REQUIRED)
=================================================
1. User navigates to protected route (e.g. /examination-sessions)
2. AppShell renders AuthGate (self-contained component, no children props)
3. AuthGate shows "ExamGuard / AUTHENTICATION REQUIRED / Continue with Google"
4. User clicks "Continue with Google"
5. signInWithGoogle() called: signInWithPopup(GoogleAuthProvider)
6. Firebase popup opens -> user selects Google account -> popup closes
7. AuthContext sets authPhase = "popup" (AuthGate shows "Waiting for Google sign-in...")
8. authPhase transitions to "exchanging" (AuthGate shows "Connecting to ExamGuard...")
9. doExchange() calls POST /api/v1/auth/firebase/exchange with Firebase ID token
10. Backend: auth.py extracts token, calls firebase_verification.verify_firebase_token()
11. firebase_verification.py: HTTP POST to identitytoolkit.googleapis.com/v1/accounts:signInWithIdToken
12. Uses FIREBASE_WEB_API_KEY (default in config.py, public by design) + Firebase ID token
13. Identity Toolkit returns Firebase user profile (uid, email, display_name)
14. Backend maps Firebase identity -> ExamGuard user (creates if new, assigns REVIEWER role)
15. Backend issues ExamGuard JWT (HS256, 30 min expiry, claims: sub, role)
16. Frontend receives JWT + user object + requiresOnboarding flag
17. AuthContext updates: user, firebaseIdToken, isAuthenticated = true, authPhase = "authenticated"
18. AuthGate detects authPhase === "authenticated" -> renders children (AppShell layout)
19. AppShell useEffect: justSignedIn && authed -> router.push("/dashboard")
20. DashboardPage mounts -> fetches exams with token -> auto-selects first exam
21. Dashboard data renders

AUTH ERROR HANDLING:
- authPhase = "error" or authError set: AuthGate shows error card with "Try Again" button
- Exchange failure: backend returns 401 with detailed message (missing config, invalid token, etc.)
- clearAuthError() resets error state before retry
- doExchange() has exchangeInProgress ref to prevent duplicate calls
